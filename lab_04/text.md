## Какие математические методы есть в программе
В программе используются не один, а набор численных методов. Их можно объяснять так: на каждом шаге времени строится сетка по радиусу,
  решается стационарная задача для излучения u, затем неявно решается задача для температуры T, а нелинейность добивается итерациями с релаксацией.

### 1. Табличная интерполяция коэффициентов
Коэффициенты σ(T), λ(T), c_T(T), k(T) заданы таблицами. В узлах сетки температура обычно не совпадает с табличными значениями, поэтому коэффициенты надо интерполировать.

**В коде используется логарифмическая интерполяция:**
```python
return np.exp(np.interp(np.log(T_clipped), ln_T_table, ln_y_table))
```

Смысл: интерполируют не y(T), а ln y от ln T. Это разумно, потому что коэффициенты меняются на порядки.

> Материальные коэффициенты зависят от температуры и заданы таблично, поэтому на каждом шаге они вычисляются интерполяцией по текущему значению температуры.

### 2. Равномерная сетка по радиусу
  Где: v1.py:308

```python
r = np.linspace(0.0, R, N + 1)
```

Область 0 <= r <= R делится на N отрезков.
Узлы: r_i = i * h,   h = R / N
Температура считается в узлах T_i ≈ T(r_i, t).

> Так как задача радиально-симметричная, пространственная сетка строится только по координате r.

### 3. Метод конечных разностей / конечных объемов по радиусу

В уравнении есть цилиндрический оператор: 1/r ∂/∂r (r λ ∂T/∂r)

Его нельзя просто заменить как обычную вторую производную, потому что есть множитель r. В коде используется консервативная форма через потоки на гранях ячеек:
  r_{i+1/2} λ_{i+1/2} (T_{i+1} - T_i) / h
  r_{i-1/2} λ_{i-1/2} (T_i - T_{i-1}) / h

  Поэтому появляются коэффициенты при T_{i-1}, T_i, T_{i+1}:

  A[n] = -rn_minus * lam_m / h
  C[n] = -rn_plus * lam_p / h
  B[n] = -A[n] - C[n] + cv_a[n] * Vn / tau

> Дифференциальный оператор по радиусу аппроксимируется разностной схемой в консервативной форме через потоки на границах ячеек.

### 4. Гармоническое среднее на гранях
  2ab / (a+b)

  Используется для λ и для χ = 1/(3k) на гранях между узлами:

  lam_iface[i] = harmonic(lam_a[i], lam_a[i + 1])
  chi_iface[i] = harmonic(chi[i], chi[i + 1])

  Зачем: коэффициенты теплопроводности и радиационного переноса могут сильно меняться. Гармоническое среднее лучше подходит для потоков через
  границу между двумя слоями.

  Фраза:

  > Коэффициенты при потоках считаются на полушагах, для этого используется гармоническое среднее соседних узловых значений.

### 5. Неявная схема по времени для температуры
  Идея неявной схемы:

  c_T (T^{n+1} - T^n) / τ = operator(T^{n+1}) + sources(T^{n+1})

  В отличие от явной схемы, новая температура находится из системы уравнений. Это устойчивее для уравнений теплопроводности.

  В коде это видно по тому, что составляется система:

  A, B, C, D
  T_pred = thomas(A, B, C, D)

> По времени используется неявная разностная схема: температура нового слоя находится из системы линейных алгебраических уравнений, а не выражается напрямую через старый слой.

### 6. Метод прогонки
  После аппроксимации каждое уравнение связывает только три соседних значения:

  A_i y_{i-1} + B_i y_i + C_i y_{i+1} = D_i

  Это трехдиагональная система. Ее решают методом прогонки, он же метод Томаса.

  В коде:

  alpha[i]
  beta[i]

  Сначала прямой ход, потом обратный ход.

  Фраза:

  > Так как разностная схема связывает только соседние узлы, матрица трехдиагональная, поэтому для решения используется метод прогонки.

### 7. Квадратурная формула трапеций для интеграла
  Электрическое поле считается так:

  E = I / (2π ∫₀ᴿ σ(T) r dr)
  integral = _trapz(integrand, r)

> Интеграл проводимости по радиусу вычисляется численно методом трапеций.

   
### 8. Последовательные итерации для нелинейности
  Уравнение для T нелинейное, потому что коэффициенты зависят от температуры:

  σ(T), λ(T), c_T(T), k(T)

  Поэтому на одном временном шаге делают итерации:

  1. Берут приближение T_curr.
  2. По нему считают коэффициенты.
  3. Решают задачу для u.
  4. Считают E.
  5. Решают линейную систему для новой температуры.
  6. Проверяют сходимость.

  Критерий:

  rel_change = max(abs(T_new - T_curr)) / max(abs(T_new))

  Фраза:

> Нелинейная задача решается методом простых итераций: коэффициенты замораживаются по текущему приближению температуры, после чего решается линейная система.

###  9. Релаксация
  T_new = omega * T_pred + (1.0 - omega) * T_curr

  Это смешивание нового решения со старым приближением. В коде omega = 0.7.

  Зачем: чтобы итерации не расходились и не давали резких скачков.

> Для стабилизации нелинейных итераций используется нижняя релаксация: берется не весь новый профиль температуры, а его смесь с предыдущим приближением.


### 10. Стационарная краевая задача для излучения
  u(r) решается отдельно на каждом временном шаге. Там нет производной по времени, поэтому это стационарная краевая задача.

  Она тоже дискретизируется по r, получается трехдиагональная система, и она тоже решается прогонкой:

  u = thomas(A, B, C, D)

  Фраза:

> На каждом шаге времени поле излучения считается квазистационарным: для текущей температуры решается отдельная краевая задача для u(r).



## Короткая Схема Алгоритма

1. Построить сетку r_i.
2. Задать начальную температуру T(r,0).
3. Для каждого времени t_n:
  1. Вычислить ток I(t_n).
  2. Начать итерации по нелинейности.
  3. По текущей T найти σ, λ, c_T, k.
  4. Решить краевую задачу для u(r).
  5. Вычислить E через интеграл проводимости.
  6. Собрать трехдиагональную систему для T.
  7. Решить ее методом прогонки.
  8. Применить релаксацию.

4. Сохранить T, I, E и построить графики.

> В работе используется неявная консервативная разностная схема по радиусу и времени. Нелинейность учитывается методом простых итераций с релаксацией. На каждой итерации решаются две трехдиагональные системы методом прогонки: сначала для стационарного поля излучения u(r), затем для температуры T(r,t).

## Где в программе исаользуется метод конечных разностей
Он реализован в местах, где дифференциальные уравнения заменяются системой алгебраических уравнений с коэффициентами A, B, C, D.

1. Для уравнения излучения u(r)
   
    Внутренние узлы сетки:
    ```python
    A[n] = -rn_minus * chi_m / h
    C[n] = -rn_plus * chi_p / h
    B[n] = -A[n] - C[n] + 3.0 * k_arr[n] * Vn
    D[n] = 3.0 * k_arr[n] * up[n] * Vn
    ```
    
    Здесь производная по r заменяется разностными отношениями между соседними узлами: u_{i-1}, u_i, u_{i+1}.
    Поэтому получается трехдиагональная система.

2. Для уравнения температуры T(r,t)
    Внутренние узлы:
    ```python
    A[n] = -rn_minus * lam_m / h
    C[n] = -rn_plus * lam_p / h
    B[n] = -A[n] - C[n] + cv_a[n] * Vn / tau
    D[n] = (
        cv_a[n] * Vn / tau * T_curr[n]
        + sigma_a[n] * E * E * Vn
        - C_LIGHT * k_a[n] * (up_a[n] - u_a[n]) * Vn
    )
    ```
    Здесь метод конечных разностей используется сразу по двум направлениям:

    - по радиусу r: аппроксимация теплопроводности;
    - по времени t: аппроксимация производной ∂T/∂t.

    Производная по времени заменена примерно так:
    ∂T/∂t ≈ (T_i^{n+1} - T_i^n) / τ

    В коде это видно по членам:
    cv_a[n] * Vn / tau и cv_a[n] * Vn / tau * T_curr[n]

3. Краевые условия тоже аппроксимируются разностями
    На оси r = 0:
     - для u: v1.py:141
     - для T: v1.py:218

    На границе r = R:
     - для T: v1.py:243


> Метод конечных разностей используется при сборке коэффициентов A, B, C, D в функциях solve_radiation и step_T. Производные по радиусу заменяются разностями между соседними узлами сетки, а производная по времени для температуры заменяется отношением (T^{n+1}-T^n)/τ. В результате получаются трехдиагональные системы, которые решаются методом прогонки.


## Как мы решаем Решить краевую задачу для u(r).
Краевую задачу для u(r) решаем в функции

**Идея**: при известной текущей температуре T(r) коэффициент k(T) и функция Планка u_p(T) уже известны. Поэтому уравнение для u становится линейной стационарной краевой задачей.

**Исходное уравнение:** 1/r d/dr ( r/k(T) · du/dr ) = 3k(T)(u - u_p(T))
**В коде оно записано через:** chi = 1.0 / (3.0 * k_arr)

1. Строим сетку
   
N = len(r) - 1
h = r[1] - r[0]

**Узлы:** r_i = i h,  i = 0, 1, ..., N
**Ищем значения:** u_i ≈ u(r_i)

1. Считаем коэффициенты по текущей температуре

k_arr = k_T(T)
up = u_planck(T)
chi = 1.0 / (3.0 * k_arr)

То есть в каждом узле знаем:
k_i = k(T_i)
u_p,i = u_p(T_i)
χ_i = 1 / (3k_i)

   
Считаем коэффициент на гранях ячеек
chi_iface[i] = harmonic(chi[i], chi[i + 1])
Это нужно, потому что поток через границу между узлами зависит от коэффициента на этой границе.

Поток излучения примерно:  F_{i+1/2} = -χ_{i+1/2} · (u_{i+1} - u_i) / h


Записываем разностное уравнение для внутренних узлов
Для каждого внутреннего узла i получаем уравнение вида: 
A_i u_{i-1} + B_i u_i + C_i u_{i+1} = D_i

В коде:
```python
  A[n] = -rn_minus * chi_m / h
  C[n] = -rn_plus * chi_p / h
  B[n] = -A[n] - C[n] + 3.0 * k_arr[n] * Vn
  D[n] = 3.0 * k_arr[n] * up[n] * Vn
```
Смысл:
  - A[n] - коэффициент при u_{n-1};
  - B[n] - коэффициент при u_n;
  - C[n] - коэффициент при u_{n+1};
  - D[n] - правая часть с u_p.


**Аппроксимируем левое краевое условие при r = 0**
  Условие:
  du/dr = 0

  Физически: на оси цилиндра симметрия, нет выделенного направления.

  В коде:
  B[0] = r_half * chi0 / h + 3.0 * k_arr[0] * V0
  C[0] = -r_half * chi0 / h
  D[0] = 3.0 * k_arr[0] * up[0] * V0

  Там нет A[0], потому что слева от оси нет узла u_{-1}.

  1. Аппроксимируем правое краевое условие при r = R
